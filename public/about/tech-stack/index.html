The technology behind OpenVaultDB

A tech stack is the tools used to build and run a product. OpenVaultDB is an early proposal for databases that belong to the user, with a public site that explains the protocol and its planned parts.

This website

The public pages are static HTML and CSS, with small browser scripts for navigation and consent. A Cloudflare Worker serves those files directly, keeping the protocol explanation readable without loading an application framework.

The product

The reference server and libraries are written in Go. The proposed stack puts TugQL queries above DALgo's storage adapters and can use inGitDB as a Git-backed engine. The site marks several backend integrations as planned, so this diagram describes the direction of the protocol rather than a claim that every adapter is available now. openvaultdb-go · TugQL · DALgo · inGitDB.

Our tools used here

This repository records features and design decisions in SpecScore files. Its installation pages are generated from versioned instructions, so a person or agent can review the same steps before setting up the ovdb CLI. SpecScore · ovdb.

Related projects

DataTug explores databases and queries. TugQL defines the query layer, DALgo provides data access, and inGitDB explores Git-backed storage. DataTug · TugQL · DALgo · inGitDB.
